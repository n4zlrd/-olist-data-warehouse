# Data

Dataset: "Brazilian E-Commerce Public Dataset by Olist" (Kaggle, user olistbr).
Download page: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The raw CSV files are NOT stored in this repository.
Download them and put them in this folder to reproduce the project.

Files used: customers, orders, order_items, order_payments, order_reviews,
products, sellers, product_category_name_translation.
